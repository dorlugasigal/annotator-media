# Reel audio

The music and sound effects are not in this repository: their licenses don't
allow sharing the files on their own. To render the reel with sound:

1. Download "Product Launch Advertising Commercial Music" by lNPLUSMUSIC from
   https://pixabay.com/music/future-bass-product-launch-advertising-commercial-music-306038/
   into `source/pixabay-306038-product-launch.mp3`.
2. Download the five Mixkit sound effects listed in `foley/CREDITS.md` from
   https://mixkit.co into `foley/`, with the file names in that table.
3. Mix them into `mix.wav` (see `../../BRIEF.md`).

The website and README use rendered videos, which are allowed.
